Claude Code は同じエンジンを CLI・Desktop・IDE・Web・モバイルで動かします。この章では、各サーフェスの役割、サーフェス間の機能差、プロバイダとプランによる可用性、端末を離れて作業する手段の違いを整理します。

<span id="ch48-overview" />

## 全体像: 6 つのサーフェス

| サーフェス                                                                                 | 向いている用途                                         | 得られるもの                                                                                                                       |
| ------------------------------------------------------------------------------------------ | ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| [CLI](/claude-code-deep-dive/ja/automation/headless/)                                      | ターミナル作業、スクリプト、リモートサーバー           | 全機能、Agent SDK、macOS での computer use <span class="badge preview">Preview</span>（Pro・Max・Ultra）、サードパーティプロバイダ |
| [Desktop](/claude-code-deep-dive/ja/platforms/desktop/)                                    | 視覚的なレビュー、並列セッション、管理された配布       | diff ビューア、アプリのプレビュー、computer use <span class="badge preview">Preview</span> と Dispatch（Pro・Max・Ultra）          |
| [VS Code](/claude-code-deep-dive/ja/platforms/ide/)                                        | ターミナルに切り替えずに VS Code 内で作業              | インライン diff、統合ターミナル、ファイルのコンテキスト                                                                            |
| [JetBrains](/claude-code-deep-dive/ja/platforms/ide/) <span class="badge beta">Beta</span> | IntelliJ・PyCharm・WebStorm などで作業                 | diff ビューア、選択範囲の共有、ターミナルセッション                                                                                |
| [Web](/claude-code-deep-dive/ja/platforms/cloud/)                                          | 手のかからない長時間タスク、オフライン中も続けたい作業 | クラウド実行（既定は Anthropic 管理）。切断後も続く                                                                                |
| [モバイル](/claude-code-deep-dive/ja/platforms/remote-control/)                            | 外出先でのタスク開始と監視                             | iOS・Android の Claude アプリから、クラウドセッション、Remote Control、Desktop への Dispatch                                       |

- スクリプト（`-p`）と Agent SDK は CLI 専用です。サードパーティプロバイダは VS Code と JetBrains（IDE のターミナルで CLI を動かす）でも使えます。
- 同じプロジェクトでサーフェスを混在できます。設定・プロジェクトメモリ・MCP サーバーは、ローカルのサーフェス間で共有されます。
- 外部連携は Chrome（[Ch54](/claude-code-deep-dive/ja/platforms/chrome-computer-use/)）、GitHub Actions・GitLab CI/CD <span class="badge beta">Beta</span>（[Ch46](/claude-code-deep-dive/ja/automation/cicd/)）、Code Review（[Ch47](/claude-code-deep-dive/ja/automation/code-review/)）、Slack <span class="badge deprecated">Deprecated</span> と Claude Tag <span class="badge beta">Beta</span>（[Ch55](/claude-code-deep-dive/ja/platforms/projects-slack-tag/)）が担います。

## 機能マトリクス: CLI だけ・Desktop だけ・VS Code で欠けるもの

| 機能                                                             | CLI                              | Desktop（Code タブ）                                                         | VS Code 拡張                                                |
| ---------------------------------------------------------------- | -------------------------------- | ---------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 権限モード                                                       | `dontAsk` を含む全モード         | Manual・Accept edits・Plan・Auto。Bypass は有効化後に表示                    | Manual・Edit automatically・Plan・Auto。Bypass は設定で追加 |
| サードパーティプロバイダ                                         | Bedrock・Agent Platform・Foundry | 既定は Anthropic API。ゲートウェイ設定か Claude Desktop on 3P                | 使える                                                      |
| `-p`・Agent SDK                                                  | 使える                           | 使えない                                                                     | 使えない（CLI 専用）                                        |
| コマンドと Skill                                                 | すべて                           | 引数形式のない端末ダイアログ型は `isn't available in this environment`       | サブセット                                                  |
| `!` Bash・Tab 補完                                               | 使える                           | 記載なし                                                                     | 使えない                                                    |
| MCP・プラグイン                                                  | 設定ファイル、`/plugin`          | Connectors UI、プラグインマネージャ                                          | `/mcp` と `/plugins` のダイアログ                           |
| 添付ファイル                                                     | 使えない                         | 画像・PDF                                                                    | 画像の貼り付け、<kbd>Shift</kbd>+ドラッグでファイル         |
| Computer use <span class="badge preview">Preview</span>          | macOS（`/mcp` で有効化）         | macOS・Windows（Linux 版は未対応）                                           | 記載なし                                                    |
| Agent Teams <span class="badge experimental">Experimental</span> | 使える                           | 使えない（Workflows は使える）                                               | 記載なし                                                    |
| Dispatch                                                         | 使えない                         | サイドバーに Dispatch セッション                                             | 記載なし                                                    |
| 定期実行                                                         | cron、CI                         | スケジュールタスク（[Ch43](/claude-code-deep-dive/ja/parallel/scheduling/)） | 記載なし                                                    |

「記載なし」は docs に記述がないことを表し、使えないことを意味しません。

## プロバイダ別の可用性

### claude.ai サブスクリプションが必要なもの

Console の API キーやサードパーティプロバイダからは使えません。

- クラウドセッションとモバイル、Remote Control
- Desktop（ゲートウェイ設定と Claude Desktop on 3P は例外）
- クラウドのスケジュールタスク（`/schedule`） <span class="badge preview">Preview</span>、Ultrareview <span class="badge preview">Preview</span>、Code Review（Team・Enterprise）
- Claude Code in Slack <span class="badge deprecated">Deprecated</span>（Pro・Max・Ultra）、Chrome 拡張、Computer use <span class="badge preview">Preview</span>（Pro・Max・Ultra）、Artifacts、音声入力

`ANTHROPIC_BASE_URL` が `api.anthropic.com` 以外を指すと、ゲートウェイの転送先にかかわらず Remote Control と server-managed settings がオフになります。

代替手段: スケジュールは `/schedule` の代わりに `/loop`、クラウドセッションの代わりに GitHub Actions か GitLab CI/CD を使います。

| CLI の機能                                                   | Sub | Console | Bedrock | AWS    | Agent P. | Foundry |
| ------------------------------------------------------------ | --- | ------- | ------- | ------ | -------- | ------- |
| Web search                                                   | ✓   | ✓       | ✗       | ✓      | 注 1     | ✓       |
| Fast mode                                                    | ✓   | ✓       | ✗       | ✗      | ✗        | ✗       |
| Auto mode                                                    | ✓   | ✓       | 注 2    | ✓      | 注 2     | 注 2    |
| Advisor <span class="badge experimental">Experimental</span> | ✓   | ✓       | ✗       | ✗      | ✗        | ✗       |
| セッション間メッセージ                                       | ✓   | 同一機  | 同一機  | 同一機 | 同一機   | 同一機  |
| Channels <span class="badge preview">Preview</span>          | ✓   | ✓       | ✗       | ✗      | ✗        | ✗       |
| GitHub Actions                                               | ✓   | ✓       | ✓       | ✗      | ✓        | ✓       |
| GitLab CI/CD <span class="badge beta">Beta</span>            | ✓   | ✓       | ✓       | ✓      | ✓        | ✗       |

- Sub = サブスクリプション、AWS = Claude Platform on AWS、Agent P. = Google Cloud の Agent Platform。
- 注 1: Opus 4・Sonnet 4・Haiku 4.5 以降のモデル。注 2: Sonnet 5 以降・Opus 4.7 以降・Haiku 5.5・Fable のみ。
- Advisor の AWS 列は changelog 2.1.300 と食い違います（[Ch5](/claude-code-deep-dive/ja/fundamentals/advisor/#ch05-cost)）。

## プラン別の可用性（claude.ai でサインインした場合）

| 機能                                                                    | Pro | Max | Ultra | Team   | Ent.   |
| ----------------------------------------------------------------------- | --- | --- | ----- | ------ | ------ |
| クラウドセッション                                                      | ✓   | ✓   | ✓     | ✓      | ✓ 注   |
| クラウドのスケジュールタスク <span class="badge preview">Preview</span> | ✓   | ✓   | ✓     | ✓      | ✓      |
| Remote Control                                                          | ✓   | ✓   | ✓     | 管理者 | 管理者 |
| Channels <span class="badge preview">Preview</span>                     | ✓   | ✓   | ✓     | 管理者 | 管理者 |
| Computer use <span class="badge preview">Preview</span>                 | ✓   | ✓   | ✓     | ✗      | ✗      |
| Dispatch（Desktop）                                                     | ✓   | ✓   | ✓     | ✗      | ✗      |
| Code Review                                                             | ✗   | ✗   | ✗     | ✓      | ✓      |
| Artifacts                                                               | ✓   | ✓   | ✓     | ✓      | ✓      |

- 「管理者」は、組織の管理者がオンにするまで使えないことを表します。
- 注: Enterprise では premium シート、または Chat + Claude Code シートが必要です。
- Ultra は旧 Max 20x、Max は旧 Max 5x の新しい名前です。Claude Code の機能は Max と Ultra で同じです。
- HIPAA 構成を適用した Enterprise 組織では、この表の一部の機能がオフになります。
- プラン限定の機能は他にもあります。Projects は Pro・Max・Ultra の public beta、Claude Tag は Team・Enterprise の public beta、セルフホスト環境は Team・Enterprise の public beta です（[Ch55](/claude-code-deep-dive/ja/platforms/projects-slack-tag/)、[Ch51](/claude-code-deep-dive/ja/platforms/self-hosted/)）。

## 端末を離れて作業する手段の比較

| 手段                                                   | きっかけ                                             | Claude が動く場所                     | 準備                                                                                                   | 詳細                                                            |
| ------------------------------------------------------ | ---------------------------------------------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------- |
| Dispatch                                               | モバイルアプリからタスクをメッセージ                 | 自分のマシン（Desktop）               | モバイルアプリと Desktop をペアリング。Pro・Max・Ultra                                                 | [Ch52](/claude-code-deep-dive/ja/platforms/desktop/)            |
| Remote Control                                         | 動作中のセッションを claude.ai/code やアプリから操作 | 自分のマシン（CLI・Desktop・VS Code） | `claude remote-control` か `/remote-control`                                                           | [Ch49](/claude-code-deep-dive/ja/platforms/remote-control/)     |
| Channels <span class="badge preview">Preview</span>    | Telegram・Discord や自前サーバーからイベントを送る   | 自分のマシン（CLI）                   | チャネルプラグインを入れる                                                                             | [Ch34](/claude-code-deep-dive/ja/extensions/channels/)          |
| Slack <span class="badge deprecated">Deprecated</span> | チャンネルで `@Claude` にメンション                  | Anthropic のクラウド                  | Slack アプリを入れ、Web 版を有効化。Pro・Max・Ultra。Claude Tag 接続済みのワークスペースでは応答しない | [Ch55](/claude-code-deep-dive/ja/platforms/projects-slack-tag/) |
| セルフホスト環境 <span class="badge beta">Beta</span>  | クラウドセッションで自組織の環境を選ぶ               | 自組織のインフラ                      | ランナーを配備。Team・Enterprise                                                                       | [Ch51](/claude-code-deep-dive/ja/platforms/self-hosted/)        |
| スケジュールタスク                                     | スケジュールを設定                                   | CLI・Desktop・クラウド                | 頻度を選ぶ                                                                                             | [Ch43](/claude-code-deep-dive/ja/parallel/scheduling/)          |

- マシンの電源が切れる場合は、クラウドセッションか Projects を使います。Remote Control と Dispatch は自分のマシンを動かすため、マシンと Claude Code（または Desktop）が動き続けている必要があります。
- Remote Control 中にマシンがスリープしても、復帰すると Claude Code が再接続します。

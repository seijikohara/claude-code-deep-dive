## Experimental・Preview・Deprecated・Removed

### <span class="badge experimental">Experimental</span>

- Advisor（[Ch5](/claude-code-deep-dive/ja/fundamentals/advisor/)）。docs 上は Anthropic API のみ
- Agent Teams（[Ch39](/claude-code-deep-dive/ja/parallel/agent-teams/)）。既定で無効
- `--teammate-mode`（[Ch39](/claude-code-deep-dive/ja/parallel/agent-teams/)）
- agent フック `type: "agent"`（[Ch28](/claude-code-deep-dive/ja/extensions/hooks/)）。prompt フックは GA
- サンドボックスの `network.tlsTerminate`（[Ch25](/claude-code-deep-dive/ja/settings/sandbox/)）

### <span class="badge deprecated">Deprecated</span>

- Opus 4.8 の fast mode（[Ch4](/claude-code-deep-dive/ja/fundamentals/fast-mode/)）。2026-11-30 に削除予定
- Claude Code in Slack（旧版）（[Ch55](/claude-code-deep-dive/ja/platforms/projects-slack-tag/)）

### <span class="badge preview">Preview</span>

- Agent view・バックグラウンドセッション（`claude agents`、`--bg`）、`/fork`（[Ch38](/claude-code-deep-dive/ja/parallel/agent-view/)）
- Channels（[Ch34](/claude-code-deep-dive/ja/extensions/channels/)）
- Computer use: CLI は macOS、Desktop は macOS と Windows（[Ch54](/claude-code-deep-dive/ja/platforms/chrome-computer-use/)）
- フルスクリーン描画（[Ch17](/claude-code-deep-dive/ja/operation/display/)）
- Ultrareview（`/code-review ultra`）（[Ch47](/claude-code-deep-dive/ja/automation/code-review/)）
- Routines・クラウドのスケジュール実行（[Ch43](/claude-code-deep-dive/ja/parallel/scheduling/)）
- Opus 5 の fast mode（[Ch4](/claude-code-deep-dive/ja/fundamentals/fast-mode/)）
- PowerShell ツール（[Ch21](/claude-code-deep-dive/ja/settings/tools/)）

### <span class="badge removed">Removed</span>

- Opus 4.7 の fast mode（2026-07-24）（[Ch4](/claude-code-deep-dive/ja/fundamentals/fast-mode/)）
- `/agents` ウィザード（2.1.198）（[Ch66](/claude-code-deep-dive/ja/summary/renames/)）
- `/vim`、`/pr-comments`、`/ultraplan`（[Ch66](/claude-code-deep-dive/ja/summary/renames/)）
- `TaskOutput` ツール（2.1.277）（[Ch66](/claude-code-deep-dive/ja/summary/renames/)）
- OTel の `claude_code.safety_event`（2.1.312 で送信停止。docs には記載が残る）（[Ch61](/claude-code-deep-dive/ja/enterprise/monitoring-costs/)）

## Beta と、公開時のラベルから変わった機能

### <span class="badge beta">Beta</span>

- MCP tasks（[Ch30](/claude-code-deep-dive/ja/extensions/mcp/)）
- Artifact テンプレート（[Ch35](/claude-code-deep-dive/ja/extensions/artifacts/)）
- GitLab CI/CD（[Ch46](/claude-code-deep-dive/ja/automation/cicd/)）
- Trusted Devices（[Ch49](/claude-code-deep-dive/ja/platforms/remote-control/)）
- セルフホスト環境（[Ch51](/claude-code-deep-dive/ja/platforms/self-hosted/)）
- Desktop の iOS Simulator ペイン、Linux 版 Desktop（[Ch52](/claude-code-deep-dive/ja/platforms/desktop/)）
- JetBrains プラグイン（製品名が Claude Code \[Beta]）（[Ch53](/claude-code-deep-dive/ja/platforms/ide/)）
- Projects、Claude Tag（[Ch55](/claude-code-deep-dive/ja/platforms/projects-slack-tag/)）
- OTel トレース（`ENABLE_BETA_TRACING_DETAILED`・`BETA_TRACING_ENDPOINT` を含む）、Contribution metrics（[Ch61](/claude-code-deep-dive/ja/enterprise/monitoring-costs/)）

### 現在は GA（ラベルなし）

- Auto mode（[Ch24](/claude-code-deep-dive/ja/settings/auto-mode/)）: What's New W13 では research preview
- Dynamic workflows（[Ch41](/claude-code-deep-dive/ja/parallel/workflows/)）: What's New W22 では research preview
- `/design`（[Ch12](/claude-code-deep-dive/ja/operation/commands/)）: What's New W34 では research preview
- Remote Control（[Ch49](/claude-code-deep-dive/ja/platforms/remote-control/)）: What's New W34 で research preview を終了
- Claude in Chrome（[Ch54](/claude-code-deep-dive/ja/platforms/chrome-computer-use/)）: 2.1.198 で GA
- Fable 5.2・Opus 5.5 の fast mode（[Ch4](/claude-code-deep-dive/ja/fundamentals/fast-mode/)）: 2.1.304 で Opus 5.5 の表記を外した

Agent Teams は 2.1.32 で research preview として公開され、現在のページは experimental と記載しています。

### GA だが条件付きのもの

- Mods（[Ch33](/claude-code-deep-dive/ja/extensions/mods/)）: 既定で有効。ターミナルは v2.1.287 以降
- `claude plugin eval`（[Ch31](/claude-code-deep-dive/ja/extensions/plugins/)）: 本体は GA。manifest の `experimental` コンテナは「形が変わりうる」と記載
- prompt フック（[Ch28](/claude-code-deep-dive/ja/extensions/hooks/)）: GA。agent フックだけが Experimental

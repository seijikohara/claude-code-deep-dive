## Beta と、公開時のラベルから変わった機能

### <Badge text="Beta" variant="note" size="small" class="badge beta" />

- MCP tasks（[MCP](/claude-code-deep-dive/ja/extensions/mcp/)）
- Artifact テンプレート（[Artifacts](/claude-code-deep-dive/ja/extensions/artifacts/)）
- GitLab CI/CD（[CI/CD](/claude-code-deep-dive/ja/automation/cicd/)）
- Trusted Devices（[Remote Control とモバイル](/claude-code-deep-dive/ja/platforms/remote-control/)）
- セルフホスト環境（[セルフホスト環境](/claude-code-deep-dive/ja/platforms/self-hosted/)）
- Desktop の iOS Simulator ペイン、Linux 版 Desktop（[Desktop](/claude-code-deep-dive/ja/platforms/desktop/)）
- JetBrains プラグイン（製品名が Claude Code \[Beta]）（[IDE](/claude-code-deep-dive/ja/platforms/ide/)）
- Projects、Claude Tag（[Projects・Slack・Claude Tag](/claude-code-deep-dive/ja/platforms/projects-slack-tag/)）
- OTel トレース（`ENABLE_BETA_TRACING_DETAILED`・`BETA_TRACING_ENDPOINT` を含む）、Contribution metrics（[監視・コスト・分析](/claude-code-deep-dive/ja/enterprise/monitoring-costs/)）

### 現在は GA（ラベルなし）

- Auto mode（[Auto mode](/claude-code-deep-dive/ja/settings/auto-mode/)）: What's New W13 では research preview
- Dynamic workflows（[Dynamic Workflows](/claude-code-deep-dive/ja/parallel/workflows/)）: What's New W22 では research preview
- `/design`（[スラッシュコマンド完全ガイド](/claude-code-deep-dive/ja/operation/commands/)）: What's New W34 では research preview
- Remote Control（[Remote Control とモバイル](/claude-code-deep-dive/ja/platforms/remote-control/)）: What's New W34 で research preview を終了
- Claude in Chrome（[Chrome と Computer use](/claude-code-deep-dive/ja/platforms/chrome-computer-use/)）: 2.1.198 で GA
- Fable 5.2・Opus 5.5 の fast mode（[Fast mode](/claude-code-deep-dive/ja/fundamentals/fast-mode/)）: 2.1.304 で Opus 5.5 の表記を外した

Agent Teams は 2.1.32 で research preview として公開され、現在のページは experimental と記載しています。

### GA だが条件付きのもの

- Mods（[Mods](/claude-code-deep-dive/ja/extensions/mods/)）: 既定で有効。ターミナルは v2.1.287 以降
- `claude plugin eval`（[プラグイン](/claude-code-deep-dive/ja/extensions/plugins/)）: 本体は GA。manifest の `experimental` コンテナは「形が変わりうる」と記載
- prompt フック（[Hooks](/claude-code-deep-dive/ja/extensions/hooks/)）: GA。agent フックだけが Experimental

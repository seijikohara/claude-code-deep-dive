2.1.292（2026-10-06）から 2.1.321（2026-11-09）までの 25 リリースを、追加・動作の変更・削除と修正に分けて読みます。2.1.297、2.1.298、2.1.313、2.1.315、2.1.320 は欠番です。2.1.303 と 2.1.308 は「Bug fixes and reliability improvements」だけのリリースです。

| 版      | 追加された内容                                                                                                                                                                              |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

## 動作の変更: 権限・auto mode・セキュリティ

| 版      | 変わった動作                                                                                                                                                                                                                                   |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2.1.321 | Claude が書いた mod は auto・bypass モードで確認なしに有効になり、`dontAsk` モードでは読み込まれない（[Ch33](/claude-code-deep-dive/ja/extensions/mods/)）                                                                                     |
| 2.1.321 | mod 自身の `$.tool.call`・`$.mcp.call` は権限プロンプトを出さない。deny ルールと組織ポリシーは引き続き効く                                                                                                                                     |
| 2.1.321 | `/bin/cp` のようにパスで書いた `cp`・`mv` も、`cp`・`mv` と同じパス検査を受ける                                                                                                                                                                |
| 2.1.319 | テレメトリや feature flag を止めた auto mode（LLM ゲートウェイ経由を含む）: サーバーが確認できない呼び出しは確認か拒否。`CLAUDE_CODE_AUTO_MODE_SERVER=0` で組み込み classifier を使う（[Ch24](/claude-code-deep-dive/ja/settings/auto-mode/)） |
| 2.1.319 | より広い deny ルールがあると、セッションの完全一致の Bash・PowerShell ask ルールは確認せずに拒否                                                                                                                                               |
| 2.1.319 | `--add-dir` のディレクトリは、そのディレクトリの信頼ダイアログを承認してからマーケットプレイスを登録                                                                                                                                           |
| 2.1.316 | Team・Enterprise のサーバー管理設定は承認なしで適用。検証できない保存コピーは拒否（[Ch58](/claude-code-deep-dive/ja/enterprise/managed-settings/)）                                                                                            |
| 2.1.309 | `sed -i` は通常の Bash プロンプトになり、`/rewind` で戻らない。`claude ultrareview` はワークスペースの信頼が必要（`--trust-workspace`）                                                                                                        |
| 2.1.302 | 権限モード未設定の `claude -p`・SDK は、サードパーティ・テレメトリ無効・新規インストールでも `default` で開始（2.1.285 からの例外を終了）（[Ch23](/claude-code-deep-dive/ja/settings/permission-modes/)）                                      |
| 2.1.300 | PreToolUse・PermissionRequest フックの `updatedInput` を Claude の入力と同様に検証。未知のキーは削除、不正な入力は拒否                                                                                                                         |
| 2.1.299 | MCP の allow ルールは名前が一致するサーバーだけに効く（`mcp__a` は `a__b` を許可しない）。`UserPromptSubmit` フックは Skill・カスタムコマンドの展開前に動く                                                                                    |

## 動作の変更: サブエージェント・Skill・MCP・出力

| 版               | 変わった動作                                                                                                                                                                                                                               |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 2.1.321          | Claude が `~/.claude/plugins` 内のファイルを扱うとき、その中の `.claude/skills` フォルダは読み込まない。ヘッドレスセッションは `.claude/skills` 内の mod の変更を再読み込み（`CLAUDE_CODE_PLUGIN_DIR_WATCH=0` で無効）                     |
| 2.1.319          | self-paced の `/loop` は、ターンが再スケジュールせずに終わると終了。`CLAUDE_CODE_LOOP_KEEPALIVE=1` で旧動作（[Ch43](/claude-code-deep-dive/ja/parallel/scheduling/)）                                                                      |
| 2.1.318          | バックグラウンドのサブエージェントは、シェルコマンドを 3 分でバックグラウンドへ移す（全プロバイダ）                                                                                                                                        |
| 2.1.317          | メイン会話と別モデルのサブエージェント・チームメイトは、そのモデルの保存済み effort か既定値を使う                                                                                                                                         |
| 2.1.312          | prompt・agent フックはセッション全体で同時 24 個まで（期限超過分は別に 12 個）。1 秒未満の `timeout` は 1 秒として扱う（[Ch28](/claude-code-deep-dive/ja/extensions/hooks/)）                                                              |
| 2.1.311          | 対話ターミナルの `ultrathink` は、Anthropic API の Opus 5.5・Sonnet 5.5・Haiku 5.5・Fable 5.1 でそのターンを xhigh に。`--output-format json`・`stream-json` は制御文字を `\uXXXX` でエスケープ                                            |
| 2.1.302          | fork サブエージェント（`subagent_type: "fork"`）を `-p`・SDK・Desktop・VS Code でも既定で有効化（`CLAUDE_CODE_FORK_SUBAGENT=0` で無効）（[Ch37](/claude-code-deep-dive/ja/parallel/subagents/)）                                           |
| 2.1.296          | Sonnet 5.5 のキャッシュ読み取りを $0.10/Mtok に訂正（`/cost`・ステータスライン・`--max-budget-usd`・SDK）。MCP のツール説明の既定上限を 4,096 文字に                                                                                       |
| 2.1.292〜2.1.299 | MCP プロトコル `2026-07-28` を既定で交渉: stdio（2.1.292）、claude.ai コネクタ（2.1.295）、クラウド・Remote Control のコネクタ（2.1.299）。`MCP_PROTOCOL_NEGOTIATION=legacy` で戻す。コネクタの 2 段階は flag を取得しないインストールだけ |

## 削除・非推奨と、主な修正

### 削除・非推奨

| 版      | 内容                                                                                                                          |
| ------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 2.1.319 | Claude in Chrome の `shortcuts_list`・`shortcuts_execute` を削除                                                              |
| 2.1.317 | Read ツールの「前回の Read 以降変更なし」の省略表示を削除。毎回内容を返す                                                     |
| 2.1.316 | Opus 4.8 の fast mode を非推奨。2026-11-30 に削除し、以後はエラー（[Ch4](/claude-code-deep-dive/ja/fundamentals/fast-mode/)） |
| 2.1.312 | OTel の `claude_code.safety_event`（2.1.307 で追加）の送信を停止                                                              |
| 2.1.300 | `claude remote-control` の `--sandbox`・`--no-sandbox` を削除（指定するとエラー）                                             |
| 2.1.299 | mod の `Text` の `bold` を非推奨（`weight` を使う）                                                                           |

### 主な修正（セキュリティとデータ消失）

| 版               | 内容                                                                                                                                |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 2.1.321          | MCP OAuth がリダイレクト先の別ホストへ refresh token などを送っていた                                                               |
| 2.1.319          | 細工した環境変数の接頭辞でコマンドの一部を権限チェックから隠せた。worktree 作成時のサンドボックス脱出                               |
| 2.1.317・2.1.321 | ディスクやクォータが満杯でトランスクリプトを失っても `claude -p` が 0 で終了していた。現在は text・json 出力で 1 で終了             |
| 2.1.304          | HEAD が detached か別ブランチのとき、`claude --worktree` が終了時に確認なしで worktree とブランチを消し、コミットを失うことがあった |
| 2.1.292          | PreToolUse フックの承認と auto mode が、ネットワーク（UNC）パスの読み取りで権限プロンプトを飛ばしていた                             |

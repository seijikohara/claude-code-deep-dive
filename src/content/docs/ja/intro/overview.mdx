## 拡張ポイントの全体図: 読み込むタイミングとコンテキストの消費

| 拡張      | 読み込むタイミング                         | コンテキストに入るもの                                                                                                                | コンテキストの消費                                                            | 章                                                    |
| --------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | ----------------------------------------------------- |
| CLAUDE.md | セッション開始時                           | 開始時に読み込む各ファイルの全文                                                                                                      | 毎リクエスト                                                                  | [Ch9](/claude-code-deep-dive/ja/fundamentals/memory/) |
| Skills    | 開始時と使用時                             | 開始時は名前と説明、使うときに全文                                                                                                    | 低い（説明は毎リクエスト）。`disable-model-invocation: true` なら呼ぶまでゼロ | [Ch29](/claude-code-deep-dive/ja/extensions/skills/)  |
| Hooks     | イベント発生時                             | なし（会話の外で実行）                                                                                                                | ゼロ。フックが出力を返したときだけ入る                                        | [Ch28](/claude-code-deep-dive/ja/extensions/hooks/)   |
| MCP       | セッション開始時                           | ツール名とサーバーの instructions。完全なスキーマは必要になってから                                                                   | ツールを使うまで低い（tool search が既定で有効）                              | [Ch30](/claude-code-deep-dive/ja/extensions/mcp/)     |
| Subagents | 起動したとき                               | 新しい分離コンテキスト（自分の system prompt、`skills:` の全文、CLAUDE.md と git status）。fork は親の会話を引き継ぐ                  | メインの会話とは別                                                            | [Ch37](/claude-code-deep-dive/ja/parallel/subagents/) |
| Plugins   | ページに記載なし                           | Skill・フック・サブエージェント・MCP サーバーをまとめた配布単位。Skill は `/my-plugin:review` の形で名前空間が付く                    | ページに記載なし                                                              | [Ch31](/claude-code-deep-dive/ja/extensions/plugins/) |
| Mods      | セッション開始時、または `/reload-plugins` | Claude Code のプロセス内で動く JavaScript / TypeScript のイベントハンドラ。ツール呼び出し・プロンプト・コマンド・画面描画を変えられる | ページに記載なし                                                              | [Ch33](/claude-code-deep-dive/ja/extensions/mods/)    |

同名の定義が複数あるとき、CLAUDE.md は全レベルが加算され、Skill・サブエージェント・MCP サーバーは名前で 1 つが勝ち、フックは全部が発火します。

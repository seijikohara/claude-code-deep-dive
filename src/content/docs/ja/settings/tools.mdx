## 主なツールの上限

| ツール        | 上限と挙動                                                                                                                                                                                                                                                |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Bash`        | タイムアウトは既定 2 分、上限 10 分（`BASH_DEFAULT_TIMEOUT_MS`・`BASH_MAX_TIMEOUT_MS`）。タイムアウトしたコマンドは止めずに背景へ移す（`sleep` で始まるものを除く）。出力が 5 GB を超えると停止                                                           |
| `Bash` の出力 | 成功は約 30,000 文字までインライン。超えるとファイルのパスと先頭 2,000 文字のプレビュー。失敗は約 10,000 文字の先頭と末尾の抜粋。読み戻しは `BASH_MAX_OUTPUT_LENGTH`（最大 150,000）、インライン上限は `bashOutputMaxChars`（最大 128,000、2.1.261 以降） |
| `Bash` の背景 | `-p`・SDK・CI・クラウドでは 30 分、`timeout` 指定で最大 2 時間。プロンプトを文字列で渡す `-p` は 10 分。手元の対話セッションは無制限（2.1.288 から）                                                                                                      |
| `Read`        | 1 回 25,000 トークン。256 KB を超えるファイルの全体読み取りは拒否。`allow_large: true` でコンテキストの残りまで読める（2.1.296 以降）。PDF は 10 ページ超で範囲指定（1 回 20 ページ）、画像は 128 MB まで                                                 |
| `Glob`        | 100 件まで、更新時刻順。`.gitignore` を無視する（`CLAUDE_CODE_GLOB_NO_IGNORE=false` で尊重）                                                                                                                                                              |
| `WebFetch`    | 1 回 100,000 文字。キャッシュ 15 分、期限 5 分。`localhost` とドットの無いホストは拒否。別ホストへのリダイレクトは追わず、Claude に返す                                                                                                                   |
| `WebSearch`   | 1 回の呼び出しで最大 8 回の検索。対話セッションは 200 回まで（1 時間に約 100 回ずつ回復、2.1.290 以降）。`-p` と SDK はターンごとに数える                                                                                                                 |

Linux と WSL では `CLAUDE_CODE_TOOL_MEMORY_LIMIT`（例 `4G`）で `Bash`・`PowerShell`・`Monitor` のメモリをまとめて制限できます。

## `-p` の init（24）と docs（46）の差

- init の 24 は、docs の現行 45 のうち 23 と、docs に無い `DesignSync` <Badge text="Undocumented" variant="default" size="small" class="badge undocumented" /> です。docs の 22 ツールが init に出ません。
- MCP サーバーが接続されたセッションでは、`ReadMcpResourceDirTool` も出ました。このツールは tools-reference に無く、SDK リファレンスのみ記載です。
- ツール名は `Agent` です。2.1.63 で `Task` から改名され、`Task(...)` は別名として今も効きます。`-p` の init は `Task` と表示します。

| init に無いツール                                                          | 理由                                                                                                                               |
| -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `Glob`・`Grep`                                                             | macOS・Linux・WSL では既定セットから外れる。検索は `Bash` の `find`・`grep`（組み込みの bfs・ugrep）で行う                         |
| `TaskCreate`・`TaskGet`・`TaskList`・`TaskUpdate`・`TodoWrite`             | 既定で出るのは Opus 4.7・Sonnet 4.6・Haiku 4.5 以前だけ。`CLAUDE_CODE_ENABLE_TODO_TOOLS=1` で 4 つの Task ツールが加わった（実測） |
| `LSP`・`PowerShell`                                                        | コードインテリジェンスのプラグインを入れるまで無効 / macOS・Linux・WSL では opt-in                                                 |
| `SendUserFile`・`ShareOnboardingGuide`                                     | Remote Control 接続中かクラウドセッションだけ / Team・Enterprise の claude.ai 契約だけ                                             |
| `SubagentHandback`・`WaitForMcpServers`                                    | auto mode のサブエージェントにだけ渡す / tool search が無効のときだけ                                                              |
| `SendFeedback`・`EndConversation`                                          | docs が `-p` では出さないと明記している                                                                                            |
| `ListMcpResourcesTool`・`ReadMcpResourceTool`                              | MCP サーバーが 0 のときは出なかった（実測）。docs に条件の記載は無い                                                               |
| `WebFetch`・`Artifact`・`AskUserQuestion`・`EnterPlanMode`・`ExitPlanMode` | 理由はドキュメントに記載なし。`WebFetch` には Team・Enterprise 向けの組織ポリシーの待ちがあるが、この環境に当てはまる説明は無い    |

## 起動モードとフラグによるツールセット（実測）

| 起動オプション                | 数  | 既定の 24 との差                                                                             |
| ----------------------------- | --- | -------------------------------------------------------------------------------------------- |
| なし（既定）                  | 24  | —                                                                                            |
| `--safe-mode`                 | 24  | 差なし                                                                                       |
| `--restricted`                | 21  | `Bash`・`Monitor`・`CronCreate`・`RemoteTrigger`・`Workflow` が消え、`Glob`・`Grep` が加わる |
| `--restricted --tools 'Bash'` | 1   | `Bash` だけ                                                                                  |
| `--bare`                      | 3   | `Bash`・`Edit`・`Read` だけ                                                                  |
| `--tools 'Bash,Edit,Read'`    | 3   | 列挙したものだけ                                                                             |
| `--tools ''`                  | 0   | 組み込みツールなし                                                                           |
| `--tools default`             | 24  | 差なし                                                                                       |
| `--allowedTools Grep`         | 26  | `Glob`・`Grep` の両方が戻る                                                                  |
| `--disallowedTools Bash`      | 24  | `Bash`・`Monitor` が消え、`Glob`・`Grep` が加わる                                            |

- 空のディレクトリで `--setting-sources project` を付け、`ENABLE_CLAUDEAI_MCP_SERVERS=false` で実行し、init の `tools` を数えました。プロンプトはローカルコマンドで、モデルへのリクエストは送っていません。
- `--restricted` は、コマンドやコードを実行するツールと `WebFetch` を外します。`--tools` で個別に名前を挙げたものだけが戻り、`default` では戻りません。
- `Bash` を外すと `Glob`・`Grep` が戻るのは docs どおりです。`Monitor` も一緒に消えました。docs のルール形式の表では、`Bash(...)` は `Bash` と `Monitor` の両方に適用されます。
- settings の allow ルールに `Glob` を書いても戻りません。戻すのは `--tools` と `--allowedTools` です。
- `--tools` は MCP ツールに効きません。MCP も外すには `--disallowedTools "mcp__*"` を使います。
- 3 つの起動モードの全体の違いは [Ch44](/claude-code-deep-dive/ja/automation/headless/) で扱います。

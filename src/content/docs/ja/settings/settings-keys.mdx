## モデルと応答

| キー                    | 既定                             | 要点                                                                                                                            |
| ----------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `model`                 | アカウントの既定モデル           | 新規セッションの開始モデル。途中の `/model` は妨げない                                                                          |
| `fallbackModel`         | 未設定（別モデルで再試行しない） | 過負荷・利用不可のときに順に試すモデルの配列。`"default"` は既定モデル                                                          |
| `availableModels`       | 未設定（全モデル）               | メイン・サブエージェント・Skill・advisor で選べるモデルを制限                                                                   |
| `modelOverrides`        | 未設定                           | Anthropic のモデル ID を、Bedrock の ARN などプロバイダ固有の ID に対応付け                                                     |
| `modelSettings`         | 未設定                           | モデルごとに effort を保存（2.1.251 以降）                                                                                      |
| `effortLevel`           | 未設定                           | `"low"`・`"medium"`・`"high"`・`"xhigh"`。保存の無いモデルの既定                                                                |
| `maxEffortLevel`        | 未設定（上限なし）               | effort の上限。全スコープで最も低い上限が効く                                                                                   |
| `alwaysThinkingEnabled` | 未設定（対応モデルで思考オン）   | `false` で拡張思考をオフ。`true` は何も変えない                                                                                 |
| `advisorModel`          | 未設定（advisor オフ）           | advisor のモデル <Badge text="Experimental" variant="caution" size="small" class="badge experimental" />（[Advisor](/claude-code-deep-dive/ja/fundamentals/advisor/)） |
| `promptCacheTtl`        | 未設定                           | メイン会話のキャッシュ TTL。`"5m"` か `"1h"`                                                                                    |
| `language`              | 未設定                           | 既定の応答言語。固定の一覧は無く、値をそのまま Claude に渡す                                                                    |

## 権限

| キー                                               | スコープ・既定                  | 要点                                                                                                                   |
| -------------------------------------------------- | ------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `permissions.allow` / `ask` / `deny`               | 未設定                          | `Tool(specifier)` ルールの配列。全ファイルの要素を結合（[権限ルール](/claude-code-deep-dive/ja/settings/permission-rules/)） |
| `permissions.defaultMode`                          | 未設定                          | 新規セッションのモード。`auto`・`bypassPermissions` は project・local では無視                                         |
| `permissions.additionalDirectories`                | 未設定                          | 追加の作業ディレクトリ。共有ファイルでは trust 待ち                                                                    |
| `permissions.blockReadsOutsideWorkingDirectories`  | 未設定                          | 作業ディレクトリ外の読み取りを全モードで拒否。`true` はどこからでも効く                                                |
| `permissions.blockWritesOutsideWorkingDirectories` | 未設定                          | `Write`・`Edit`・`NotebookEdit` の外部書き込みを全モードで拒否                                                         |
| `permissions.denyInsteadOfPrompting`               | User or managed                 | 承認待ちになる呼び出しを拒否して、セッションを止めない                                                                 |
| `permissions.disableBypassPermissionsMode`         | 未設定                          | `"disable"` で `bypassPermissions` を禁止                                                                              |
| `disableAutoMode`                                  | 未設定                          | `"disable"` で auto mode を <kbd>Shift</kbd>+<kbd>Tab</kbd> の巡回から外す                                             |
| `autoMode`                                         | User or managed                 | auto mode の分類器に独自のルールを追加（[Auto mode](/claude-code-deep-dive/ja/settings/auto-mode/)）                        |
| `useAutoModeDuringPlan`                            | User, local, or managed・`true` | plan mode でも分類器がシェルコマンドを審査                                                                             |
| `allowManagedPermissionRulesOnly`                  | Managed                         | user・project・local・`--settings` の権限ルールと `--allowedTools` を無視                                              |

## フック・MCP・プラグイン・Skill

| キー                                               | 既定                         | 要点                                                                                                |
| -------------------------------------------------- | ---------------------------- | --------------------------------------------------------------------------------------------------- |
| `hooks`                                            | 未設定                       | イベントごとのフック定義。全ファイルでマージ（[Hooks](/claude-code-deep-dive/ja/extensions/hooks/)） |
| `disableAllHooks`                                  | 未設定                       | フック、カスタムステータスライン、ファイル候補コマンドを止める                                      |
| `allowedHttpHookUrls`                              | 未設定（全 URL）             | HTTP フックの送信先を制限                                                                           |
| `enableAllProjectMcpServers`                       | 未設定（サーバーごとに確認） | project の `.mcp.json` の全サーバーを承認                                                           |
| `enabledMcpjsonServers` / `disabledMcpjsonServers` | 未設定                       | `.mcp.json` のサーバーを個別に承認・拒否                                                            |
| `allowedMcpServers` / `deniedMcpServers`           | 未設定                       | 追加できる MCP サーバーの許可・拒否リスト（[MCP](/claude-code-deep-dive/ja/extensions/mcp/)）      |
| `disableClaudeAiConnectors`                        | `false`                      | claude.ai コネクタを取得しない。`true` はどこからでも効く                                           |
| `enabledPlugins`                                   | 未設定                       | `"plugin@marketplace": true` の形でプラグインをオン・オフ                                           |
| `extraKnownMarketplaces`                           | 未設定                       | マーケットプレイスを追加登録。共有ファイルでは trust 待ち                                           |
| `skillOverrides`                                   | 全 Skill が `"on"`           | `"on"`・`"name-only"`・`"user-invocable-only"`・`"off"`                                             |
| `disableBundledSkills`                             | 未設定                       | バンドル Skill と workflow を外す                                                                   |
| `disableSkillShellExecution`                       | 未設定                       | Skill とカスタムコマンドのインラインシェル実行を止める                                              |

## 表示・セッション・コンテキスト

| キー                       | 既定               | 要点                                                                                      |
| -------------------------- | ------------------ | ----------------------------------------------------------------------------------------- |
| `theme`                    | `"dark"`           | `"auto"`・`"light"`・`*-daltonized`・`*-ansi`・`"custom:<slug>"`                          |
| `tui`                      | 未設定（自動選択） | `"default"`（従来の描画）か `"fullscreen"` <Badge text="Preview" variant="tip" size="small" class="badge preview" />     |
| `viewMode`                 | 未設定             | `"default"`・`"verbose"`・`"focus"`。`--verbose` が優先                                   |
| `editorMode`               | `"normal"`         | `"vim"` で入力欄を Vim キーバインドに                                                     |
| `statusLine`               | 未設定             | ステータスラインを描くコマンド（[ステータスライン](/claude-code-deep-dive/ja/operation/statusline/)） |
| `cleanupPeriodDays`        | `30`               | トランスクリプトなどの保持日数。最小 `1`                                                  |
| `autoCompactEnabled`       | `true`             | 自動圧縮のオン・オフ（[コンテキスト管理](/claude-code-deep-dive/ja/fundamentals/context/)）            |
| `autoCompactWindow`        | 未設定（モデル別） | 自動圧縮の基準。`100000`〜`1000000` トークン                                              |
| `autoMemoryEnabled`        | `true`             | auto memory の読み書き（[メモリ](/claude-code-deep-dive/ja/fundamentals/memory/)）           |
| `claudeMdExcludes`         | 未設定             | 読まない CLAUDE.md の glob。絶対パスと照合                                                |
| `bashOutputMaxChars`       | 未設定（30,000）   | Bash 出力のインライン上限。`4000`〜`128000` に丸める                                      |
| `fileCheckpointingEnabled` | `true`             | 編集前のスナップショット（`/rewind` 用）                                                  |

## サンドボックス・エージェント・Git・認証・更新

| キー                                         | 既定           | 要点                                                                                                 |
| -------------------------------------------- | -------------- | ---------------------------------------------------------------------------------------------------- |
| `sandbox.enabled`                            | `false`        | Bash コマンドのサンドボックス（[サンドボックス](/claude-code-deep-dive/ja/settings/sandbox/)）                 |
| `sandbox.filesystem.allowWrite` / `denyRead` | 未設定         | サンドボックス内の書き込み先を追加、読み取りを禁止                                                   |
| `sandbox.network.allowedDomains`             | 未設定         | 通信先を事前に許可。`*.example.com` はサブドメインに一致                                             |
| `agent`                                      | 未設定         | メインスレッドを名前付きサブエージェントとして動かす。`--agent` が優先                               |
| `worktree.baseRef`                           | `"fresh"`      | `"fresh"` は `origin/<default-branch>`、`"head"` はローカルの `HEAD` から分岐                        |
| `teammateMode`                               | `"in-process"` | `"auto"`・`"tmux"`・`"iterm2"` で分割ペイン表示 <Badge text="Experimental" variant="caution" size="small" class="badge experimental" /> |
| `attribution`                                | 未設定         | commit・PR の帰属表記。`false` ですべて非表示（2.1.281 以降）                                        |
| `includeGitInstructions`                     | `true`         | git の手順と git status のスナップショットを Claude に渡す                                           |
| `apiKeyHelper`                               | 未設定         | 認証情報を出力するコマンド。`/bin/sh`（Windows は `cmd`）で実行                                      |
| `forceLoginMethod`                           | 未設定         | `"claudeai"`・`"console"`・`"gateway"` に限定                                                        |
| `autoUpdatesChannel`                         | `"latest"`     | `"stable"` は通常 1 週間ほど前の版                                                                   |
| `env`                                        | 未設定         | セッションとサブプロセスの環境変数（[環境変数](/claude-code-deep-dive/ja/settings/env-vars/)）           |

解析・連結・キューイング

解析と Skill の連結

  • コマンドはメッセージの先頭にあるときだけ認識されます。後ろのテキストは引数になります。一覧の <arg> は必須、[arg] は任意の引数です。
  • 端末のプロンプトでは、先頭に Skill を重ねられます。/skill-a /skill-b do XYZ は両方を読み込み、末尾のテキストを各 Skill に引数として渡します。
  • 展開されるのは先頭の Skill と後続の最大 5 個（計 6 個）です。インラインで呼べるユーザー起動 Skill ではないトークンで展開は止まります。
  • フォークしたサブエージェントで動く Skill（/code-review など）や、引数が別のコマンドで始まりうる Skill（/loop）でも、展開はそこで終わります。
  • claude -p と Agent SDK では先頭の Skill だけを読み込み、残りは引数になります。
  • 文中の run the tests, then /com でも補完できますが、挿入したコマンドは文字列として入るだけです。

メニュー照合と非表示コマンド

/ メニューの照合（v2.1.236 以降）

  • 先頭の候補を強調するのは、/ の後の文字がコマンド名か別名の先頭、または名前の中の単語の先頭と一致したときだけです。:・_・- の区切りは無視します。
  • 例: /adddir は /add-dir を、/new は別名を通じて /clear を強調します。Enter で強調中の候補を実行します。
  • 打ち間違えたときは何も強調しません。近い候補は一覧に残り、Tab か矢印キーで選べます。Enter は入力どおりに送信し、Unknown command になります。
  • プラグインの Skill は短い名前でも一致します。/deploy で myplugin:deploy-app が見つかり、挿入すると /myplugin:deploy-app と書かれます。

種類振る舞い

/config の主要キー (1/2): 書式と true|false のキー

  • 書式は /config [key=value ...]（別名 /settings）です。引数なしで Settings 画面を開きます。
  • key=value を 1 組以上並べると、画面を開かずに設定します。例: /config thinking=false、/config theme=dark、/config model=sonnet
  • key=value は -p と Remote Control でも動きます（2.1.181）。
  • パネルで確認が要る設定（例: autoContinueAtUsageLimit）は、key=value で無効にはできますが、有効にはできません。

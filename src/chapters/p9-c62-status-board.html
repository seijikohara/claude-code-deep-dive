実験的・プレビュー機能一覧

2.1.321 時点で一般提供（GA）でない機能を、ステータス別に一覧します。ラベルは各機能のドキュメントページの現在の表記に従います。公開時のラベルから変わった機能も併記します。

Experimental・Preview・Deprecated・Removed

Experimental

  • Advisor（Ch5）。docs 上は Anthropic API のみ
  • Agent Teams（Ch39）。既定で無効
  • --teammate-mode（Ch39）
  • agent フック type: "agent"（Ch28）。prompt フックは GA
  • サンドボックスの network.tlsTerminate（Ch25）

Deprecated

  • Opus 4.8 の fast mode（Ch4）。2026-11-30 に削除予定
  • Claude Code in Slack（旧版）（Ch55）

Preview

  • Agent view・バックグラウンドセッション（claude agents、--bg）、/fork（Ch38）
  • Channels（Ch34）
  • Computer use: CLI は macOS、Desktop は macOS と Windows（Ch54）
  • フルスクリーン描画（Ch17）
  • Ultrareview（/code-review ultra）（Ch47）
  • Routines・クラウドのスケジュール実行（Ch43）
  • Opus 5 の fast mode（Ch4）
  • PowerShell ツール（Ch21）

Removed

  • Opus 4.7 の fast mode（2026-07-24）（Ch4）
  • /agents ウィザード（2.1.198）（Ch66）
  • /vim、/pr-comments、/ultraplan（Ch66）
  • TaskOutput ツール（2.1.277）（Ch66）
  • OTel の claude_code.safety_event（2.1.312 で送信停止。docs には記載が残る）（Ch61）

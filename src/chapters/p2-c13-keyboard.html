キーボードと入力

対話セッションのプロンプトで使うキーと入力の仕組みです。この章では、制御キー、readline 編集、入力プレフィックスと複数行、シェルモード、キューイングと履歴、貼り付け、Vim モード、/btw・トランスクリプト・/diff を扱います。キーの割り当て変更は Ch14 です。

readline 編集と単語の区切り

キー動作
Ctrl+A / Ctrl+E論理行の先頭 / 末尾へ
Ctrl+K行末まで削除（削除文字列を保存）
Ctrl+U行頭まで削除。繰り返すと複数行にわたって消す
Ctrl+W直前の空白まで削除
Ctrl+Y最後に削除した文字列を貼り付け
Alt+Y（Ctrl+Y の後）削除履歴を順に切り替え

  • 単語系のキー（Alt+B/F/D、macOS の Option+Delete、Windows の Ctrl+Backspace）は英数字の連続を 1 単語とみなします。src/utils/foo.ts で Alt+B を繰り返すと ts、foo、utils、src の先頭で止まります。

  • 単語系のキーと Ctrl+W にはアクションが無く、keybindings.json では変えられません。
  • 削除範囲が [Pasted text #N] にかかると、プレースホルダーごと消えます。Ctrl+Y で戻せます。

シェルモード（!）とバックグラウンド実行

  • ! npm test のように先頭に ! を付けると、Claude を通さずにコマンドを実行します。承認は不要です。
  • コマンドと出力は会話のコンテキストに入り、Claude は続けて自動で応答します。費用は通常のプロンプトと同じです。応答させずに足すだけなら respondToBashCommands: false にします。
  • Tab で、このプロジェクトの過去の ! コマンドから補完します。/ を含むトークンではパス補完が出ます（Windows でも /）。
  • 空の入力で Esc・Backspace・Ctrl+U を押すと抜けます。! で始まる文を空の入力に貼り付けても、シェルモードに入ります。
  • strict sandbox mode の対象セッションを除き、サンドボックスの外で動きます。サンドボックスは Claude が実行するコマンドに掛かるためです（Ch25）。
  • Claude の作業中に送った ! コマンドはターン終了まで待ち、順に 1 つずつ実行します。

Ctrl+B とバックグラウンドのコマンド

  • 実行中の Bash をバックグラウンドへ移すとタスク ID が返り、出力はファイルに書かれます。Claude は Read ツールで読みます。
  • タイムアウトしたコマンドは、sleep で始まるものを除き、止めずにバックグラウンドへ移ります。
  • 出力が 5GB を超えると打ち切ります。macOS・Linux では、30 分以上アイドルでメモリ逼迫が報告されると止めます（CLAUDE_CODE_DISABLE_BG_SHELL_PRESSURE_REAP=1 で無効）。
  • 終了時に後片付けします。セッションをバックグラウンドに回した場合は、そのセッションで動き続けます（Preview、Ch38）。
  • CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1 か --bare で、バックグラウンド化と Ctrl+B が無効になります。

キューイング: 作業中に送ったメッセージの扱い

  • Claude の作業中に Enter を押すと、割り込まずにキューへ入れます。Claude が着手するまで灰色で表示します。IDE の選択範囲は Enter 時点のものを保ちます。
  • メッセージ: 実行中のツール呼び出しが終わった時点で、同じターンのうちに渡します。ターン終了時に残っていれば、入力順に自動で送ります。
  • コマンドと !: ターン終了まで保留し、順に 1 つずつ実行します。/status・/model などすぐ動くコマンドは Ch12 にあります。
  • Esc は下書きを送らずにターンを止め、キューの中身はすぐ送ります。
  • 取り戻し: 1 行目で ↑ を押すと、キューのメッセージとコマンドを 1 件 1 行で入力欄の先頭に戻します。! コマンドは、入力欄が空で他にキューが無いときだけ戻り、シェルモードに切り替わります。
  • ← でセッションをバックグラウンドに回すと（Preview、Ch38）、メッセージは一緒に移ります。コマンド・!・IDE 選択付きメッセージが残っていると Cannot open agents で止まります。

履歴・逆順検索・退避と下書きの復元

  • 入力履歴は作業ディレクトリごとに保存され、↑ で同じプロジェクトの過去セッションまで遡れます。/clear の後は新しいセッションの入力が先に並びます。
  • 同じ入力を続けて送ると 1 件として記録します。! による履歴展開は既定で無効です。
  • 貼り付けを含む入力を呼び戻して送ると、貼り付けた全文を再送します（次のスライド）。
  • Ctrl+C で消した下書きは、直後に空の入力で ↑ を押すと戻ります（v2.1.288 以降）。送信後でも、セッション内で直近 10 件を貼り付けや画像ごと ↑ で辿れ、終了時に破棄されます（v2.1.292 以降）。
  • Ctrl+S（chat:stash）は入力を退避して空にし、空の入力で押すと文字・カーソル位置・貼り付け・入力モードごと戻します。

貼り付け: 画像・長文・不可視文字

  • 画像は Ctrl+V（iTerm2 は Cmd+V、Windows と WSL は Alt+V。WSL は両方）で、カーソル位置に [Image #N] チップとして入ります。選択ダイアログでは Attachments コンテキストで移動・削除します。
  • 800 文字超か 3 行超の貼り付けは [Pasted text #1 +120 lines] のように畳まれ、送信時は全文を送ります。ファイル丸ごとや長いログは、ファイルに書いて Claude に読ませるほうが会話を読みやすく保てます。
  • 送信時、Claude には貼り付け部分が「入力ではなく貼り付けた文」として示されます。中の指示には、入力した文が求めた場合だけ従うよう伝えます。feature flag を取得しないセッションでは示しません。
  • VS Code の統合ターミナルは、非常に大きな貼り付けで文字を落とすことがあります。
  • 貼り付けた中身は ~/.claude/paste-cache/ に残り、履歴から呼び戻すと後のセッションでも全文を再送します。cleanupPeriodDays を過ぎたキャッシュは消えます。
  • キャッシュが消えていた場合、[Pasted text #N] の文字列はそのまま送りません。通常の入力ではプレースホルダーを外して残りを送ります。! や / のコマンド、または空になる入力では、送信を取りやめて入力を残します。
  • Enter 時に、タグ文字・双方向制御文字・ゼロ幅スペースなど表示されない文字を取り除きます（ペルシア文字やインド系文字の結合子、絵文字の異体字セレクタは残す）。
  • 何か取り除いた場合、その Enter では送らず、Removed 3 invisible characters · review and press Enter to send のような通知とともに入力欄へ戻します。
  • claude "fix the login bug" のようにコマンドラインで渡した入力は、通知を出して除去後に送ります。除去後に / で始まる場合だけ入力欄に置きます。

サイドクエスチョン: /btw

  • /btw what was the name of that config file again? のように、会話履歴に残さずに今のセッションについて尋ねます。
  • 答えは会話に既にあるもの（メッセージ、返答、ツール結果）だけから作ります。ツールは使えません。ツール呼び出しを文字で書いた場合は、何も実行していない旨の注記が付きます。
  • 作業中も割り込まずに使え、書きかけの返答以外はすべて見えます。毎回、直近 20 件の過去のやり取りも渡します。スレッドはメモリ上だけにあり、終了で消えます。
  • 返答は 1 回きりです。ツール付きで続けるには f でフォークし、バックグラウンドのサブエージェントにします（ローカルのみ）。
  • 引数なしの /btw は直近のやり取りでオーバーレイを開き直します。
  • サブエージェントのトランスクリプトを開いているとそちらから答えます（v2.1.314 以降）。VS Code 拡張では追加の質問ができるパネルになります（v2.1.227 以降）。
オーバーレイのキー動作
Space Enter Esc閉じてプロンプトへ戻る
↑ ↓答えをスクロール
Shift+← →、[ ]、Tab過去の答えを行き来（v2.1.257 以降。v2.1.187〜2.1.256 は ← →）
c答えを Markdown のままコピー

トランスクリプト・フォーカス表示・/diff

  • Ctrl+O はツールの詳細と、各返答の時刻・モデルを表示します。Called slack 3 times のような MCP 呼び出しや、Message from @<sender> も展開します。
  • q・Ctrl+C・Esc で閉じます（transcript:exit）。クラシック描画では Ctrl+E で全表示を切り替えます。
  • フルスクリーン描画（Preview）では、?・{ }・/ 検索・[・v が加わります（Ch17）。
  • /focus（フルスクリーン専用、Preview）は、最後のプロンプト、diffstat 付きのツール要約 1 行、最終応答だけを表示します。要約はサブエージェント数も数えます。選択はセッションをまたいで残ります。
  • 設定 viewMode（default/verbose/focus）は /focus の選択と verbose より優先します。/focus は 2.1.110 で Ctrl+O から分かれました。
  • /diff はフルスクリーン描画（Preview）では会話の横に diff パネルを開き、クラシック描画ではプロンプトの上に diff ダイアログを開きます。どちらも組み込み mod cc-plugin-diff が描き、/plugin で無効にすると旧ビューアになります。
  • パネルの要件は git リポジトリ、幅 110 桁以上、v2.1.287 以降です。144 桁以上なら Claude の編集開始で自動で開き、閉じると次に /diff を実行するまで閉じたままです。
  • 編集のたびに更新し、ターンごとの T1 T2 … を選べます。ターン表示は Claude のファイル編集から作るので、シェル経由の変更は Current にだけ出ます。
  • ask はそのファイルの diff を次のプロンプトに添付します。Ctrl+X B（app:cycleDiffBase）で比較対象をセッション → 未コミット → ブランチ分岐点と切り替え、リポジトリごとに記憶します。
  • テストと生成ファイルは一覧から外れ、セッション前の変更は 1 行に畳まれます。サブモジュールは指すコミットが変わったときだけ 1 項目で出ます。

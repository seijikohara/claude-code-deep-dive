05

Advisor Experimental

作業中のメインモデルが、判断の要所だけ別のモデルに相談する仕組みです。この章では、有効化の経路、モデルの組み合わせ制約、セッション中の表示、コストとキャッシュ、他の手段との使い分けを扱います。

Advisor とは Experimental

  • メインモデルが作業中に、別のモデル（advisor）へ相談するサーバー側ツールです。
  • advisor は、ツール呼び出しと結果を含む会話全体を受け取ります。
  • 呼ぶタイミングは Claude が判断します。方針を決める前、同じエラーが続くとき、完了を宣言する前に呼びやすい傾向があります。
  • 呼び出し回数を制限・強制する設定はありません。相談させたいときはプロンプトで頼みます（例: consult the advisor before you continue）。
  • 試した手順が失敗したときや、ファイルの内容と矛盾するときは、Claude は助言に従わずに食い違いを示します。

要件（すべて必要）

  • Anthropic API のみ。Bedrock・Claude Platform on AWS・Agent Platform・Foundry では使えません。LLM ゲートウェイ経由の場合は、リクエストをそのまま Anthropic API へ転送するかどうかで決まります。
  • 対応するメインモデル: Fable、Opus 4.6 以降、Sonnet 4.6 以降、Haiku 4.5、Haiku 5.5
  • feature flag の取得。DISABLE_TELEMETRY など取得を止める変数があると、advisor は無効のままです。

ドキュメントは「挙動・価格・提供範囲は変わる可能性がある」と明記しています。

--advisor が起動時に止まる条件と、現在値の確認

--advisor は、次のどれかに当たると起動時にエラーで終了します。

  • メインモデルが advisor に対応していない
  • 指定したモデルが advisor になれない（例: Haiku 4.5）
  • availableModels の許可リストに含まれていない
  • Fable の usage credits への同意が済んでいない

バックグラウンドセッションでは終了せず、advisor なしで起動します。指定したモデルがメインモデルより格下の場合は、エラーにならずに起動し、メインモデルは advisor なしで動きます。

$ claude -p "/advisor"
Advisor: off
Usage: /advisor 

$ claude -p --model sonnet --advisor opus "/advisor"
Advisor: Opus 5.5
Usage: /advisor

user / local 設定を読ませない空のディレクトリで、--setting-sources project を付けて実行

  • Haiku 4.5 は advisor を呼べますが、advisor にはなれません。
  • サブエージェントは advisor の設定を引き継ぎ、自分のモデルでもう一度組み合わせを検査します。
  • メインモデルより格下の advisor は、メインのリクエストには付けられません。ただし、条件を満たすサブエージェントは使えます。
  • API が組み合わせを拒否した場合、Claude Code はそのリクエストを advisor なしで再送します。エラーは表示されません。
  • 別の advisor を選び直した場合、反映されるのは /clear か /compact の後、または新しいセッションからです。
$ claude -p --model opus --advisor sonnet "/advisor"

at least as capable as the main model). The advisor will not
be used for the main model.          → exit 0（起動は続く）

$ claude -p --model claude-haiku-4-5 \
    --advisor claude-haiku-4-5 "/advisor"

セッション中の表示と、Fable を advisor にする条件

トランスクリプトの表示

呼び出し中は、advisor のモデル名とともに Advising の行が出ます。結果が返ると、行は次のいずれかに変わります。

結果表示と読み方
Reviewedadvisor が会話を確認した。助言の本文は Ctrl+O で読める
DeclinedAdvisor declined to advise on this request。理由があれば Ctrl+O で読める
UnavailableAdvisor unavailable (<error_code>)。呼び出しが失敗した

Fable advisor と usage credits

  • Fable の利用が usage credits に課金されるプランでは、Fable を advisor にした分も同じく課金されます。
  • 課金への 1 回限りの同意が済むまで、次のように扱われます。
    • /advisor fable は保存されず、/model fable の実行を案内される。
    • claude --advisor fable は起動時に終了する。バックグラウンドセッションでは advisor なしで起動する。
    • advisorModel に Fable が保存済みでも、リクエストは advisor なしで送られる。
  • 同意するには /model fable を実行し、Fable で続けることを選びます。そのあとで advisor に Fable を選びます。
  • バージョン要件があります。Fable 5.2 は v2.1.321 以降、Fable 5.1 は v2.1.257 以降、Haiku 5.5 は v2.1.293 以降が必要です。
出典: advisor#what-you-see-during-a-session · advisor#fable-advisor-and-usage-credits

コスト・プロンプトキャッシュ・他の手段との使い分け

  • コスト: advisor が会話を読むたびに、advisor モデルの料金でトークンを消費します。この分はメインモデルの利用とは別にかかります。
    • API 課金: advisor の入出力トークンを、advisor モデルの単価で支払う。
    • サブスクリプション: プランの利用上限に計上される（Fable は前スライドの usage credits）。
    • /usage のセッション合計に含まれる。
  • キャッシュ: /advisor の切り替えでは、メインモデルのキャッシュは壊れません（モデル切り替えとは違います）。
  • advisor 自身の会話の読み込みはキャッシュされません。呼ぶたびに、トランスクリプト全体を読み直します。

Claude Platform on AWS での提供可否が食い違っています。

  • advisor ページ: 「Claude Platform on AWS では使えない」
  • changelog 2.1.300: 「Added /advisor on Claude Platform on AWS」。advisor は /advisor・advisorModel・--advisor のいずれかで選ぶまで動きません。
手段強いモデルが動く時点開始のきっかけ
Advisor作業途中の判断の要所Claude が必要と判断して呼ぶ
opusplanplan mode の間（availableModels が許す場合）。実行時は Sonnet に切り替わるユーザーが plan mode に入る

速いメインモデルと強い advisor を組み合わせると、強いモデルを常時使うより安くなりやすい、とドキュメントは説明しています。

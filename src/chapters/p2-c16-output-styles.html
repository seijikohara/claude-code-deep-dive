出力スタイル

セッション全体の応答の役割・口調・形式を、システムプロンプトへの指示で切り替える仕組みです。この章では、組み込みの 5 スタイルと切り替え経路、カスタムスタイルのファイル・frontmatter・効き方を扱います。

組み込みスタイルと切り替え方

スタイル変わること
defaultスタイル指示を足さない。ソフトウェア開発向けの標準システムプロンプトだけで動く
Proactiveすぐ実装に入り、定型の判断は仮定で進める。頼まれない限り plan mode に入らない。削除や本番系の変更の前は会話で確認する。権限モードは変えない
Concise1 文目で結果を述べ、前置き・逐次説明・まとめを省く。頼まれた説明とエラー・警告・破壊的操作の確認は省略しない（v2.1.237 以降）
Explanatory判断理由を 2〜3 点まとめた ★ Insight ブロックを会話内に添える。ファイルにはコメントとして書かない
LearningInsight に加え、設計判断を含む数行を TODO(human) で残し、● Learn by Doing の依頼を出して待つ
  • /output-style <style> は大文字小文字を区別しません。引数なしで一覧を出します（v2.1.269 以降。-p・SDK・Remote Control でも動く）。
  • /config の Output style とコマンドは、.claude/settings.local.json に保存します。
  • 設定値 "outputStyle": "Explanatory" は大文字小文字を区別します。explanatory は Default になります。
  • 途中の切り替えは次のメッセージから効きます（v2.1.251 以降）。キャッシュへの影響は Ch6 で扱います。
$ claude -p "/output-style"
Output style: default

Available styles:
- default (current)
- Proactive: Claude executes immediately, minimizes …
- Concise: Claude responds tersely, leading with results …
- Explanatory: Claude explains its implementation choices …
- Learning: Claude pauses and asks you to write small …

Usage: /output-style

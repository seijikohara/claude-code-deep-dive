動作の変更（1/2）: 権限・auto mode・セキュリティ

版変わった動作
2.1.321Claude が書いた mod は auto・bypass モードで確認なしに有効になり、dontAsk モードでは読み込まれない（Ch33）
2.1.321mod 自身の $.tool.call・$.mcp.call は権限プロンプトを出さない。deny ルールと組織ポリシーは引き続き効く
2.1.321/bin/cp のようにパスで書いた cp・mv も、cp・mv と同じパス検査を受ける
2.1.319テレメトリや feature flag を止めた auto mode（LLM ゲートウェイ経由を含む）: サーバーが確認できない呼び出しは確認か拒否。CLAUDE_CODE_AUTO_MODE_SERVER=0 で組み込み classifier を使う（Ch24）
2.1.319より広い deny ルールがあると、セッションの完全一致の Bash・PowerShell ask ルールは確認せずに拒否
2.1.319--add-dir のディレクトリは、そのディレクトリの信頼ダイアログを承認してからマーケットプレイスを登録
2.1.316Team・Enterprise のサーバー管理設定は承認なしで適用。検証できない保存コピーは拒否（Ch58）
2.1.309sed -i は通常の Bash プロンプトになり、/rewind で戻らない。claude ultrareview はワークスペースの信頼が必要（--trust-workspace）
2.1.302権限モード未設定の claude -p・SDK は、サードパーティ・テレメトリ無効・新規インストールでも default で開始（2.1.285 からの例外を終了）（Ch23）
2.1.300PreToolUse・PermissionRequest フックの updatedInput を Claude の入力と同様に検証。未知のキーは削除、不正な入力は拒否
2.1.299MCP の allow ルールは名前が一致するサーバーだけに効く（mcp__a は a__b を許可しない）。UserPromptSubmit フックは Skill・カスタムコマンドの展開前に動く
出典: changelog 2.1.299, 2.1.300, 2.1.302, 2.1.309, 2.1.316, 2.1.319, 2.1.321

IDE

VS Code 拡張と JetBrains プラグイン、そして CLI が IDE とつながる仕組みです。この章では、VS Code の要件と開始時の権限モード、選択範囲と差分、claudeCode.* 設定とショートカット、JetBrains、IDE MCP サーバーと /ide・--ide を扱います。

VS Code 拡張: 要件と開始時の権限モード

  • VS Code 1.94.0 以降が必要です。アカウントは有料の Claude プラン（Pro・Max・Ultra・Team・Enterprise）か Claude Console で、API キーは不要です。
  • Cursor にもそのまま入ります。Devin Desktop・Kiro などのフォークは、拡張ビューか Open VSX から入れます。
  • 拡張のバージョンは、同梱する Claude Code のバージョンです。「v2.1.286 以降が必要」な機能には拡張 2.1.286 以降が要ります。
  • 拡張はチャットパネル用に専用の CLI を同梱しますが、claude を PATH に追加しません。統合ターミナルで claude を使うには CLI を別途インストールします。
  • パネルはエディタツールバーの Spark アイコン（ファイルを開いているとき）、アクティビティバー、コマンドパレット、ステータスバーの ✻ Claude Code から開きます。
  • 拡張と CLI は会話履歴を共有します。CLI で続けるには claude --resume を使います。

新しい会話の開始モード（最初に当たったもの）

  1. claudeCode.initialPermissionMode（user 設定のみ。auto は指定不可）
  2. モード表示で最後に選んだ Manual・Edit automatically・Auto（Plan と Bypass はその会話だけ）
  3. managed settings か ~/.claude/settings.json の permissions.defaultMode
  4. プラン・プロバイダ・組織設定による組み込みの既定
  • プロジェクトの .claude/settings.json・settings.local.json は開始モードに使いません。
  • claudeCode.claudeProcessWrapper を設定すると 3 と 4 は使われず、1・2 がなければ Manual で始まります。
  • Bypass permissions は claudeCode.allowDangerouslySkipPermissions がオンのときだけ表示されます。オフのまま bypassPermissions を指定すると Manual で始まります。
  • 表示名: Manual＝default、Edit automatically＝acceptEdits。モード自体は Ch23 で扱います。

選択範囲・@メンション・差分のレビュー

  • エディタで選択したテキストと、開いているファイルの名前は自動で Claude に渡ります。Option+K（Windows・Linux は Alt+K）で @app.ts#5-10 のような参照を挿入します。
  • claudeCode.attachSelection（v2.1.300 以降）と claudeCode.attachOpenFile（v2.1.271 以降）をオフにすると、それぞれ渡さなくなります。統合ターミナルの claude にも効きます。
  • チャットパネルでは、files.exclude・search.exclude に一致するファイルや git が無視するファイルの選択テキストを渡しません。統合ターミナルにはこの除外がないため、Read の deny ルールで防ぎます。
  • @ はあいまい一致です（フォルダは末尾に /）。@terminal:name でターミナルの出力を参照します。PDF はページ範囲を指定して読めます（poppler-utils が必要）。
  • @browser で Claude in Chrome を使います（Chrome 拡張 1.0.36 以降、Ch54）。
  • Manual では、編集のたびに元と提案の差分を並べて表示し、許可を求めます。差分を直接編集してから受け入れると、Claude は変更されたことを知らされます。
  • 変更ごとの Accept this change・Reject this change で 1 か所ずつレビューできます（v2.1.275 以降）。100 か所を超える差分にはこのボタンが出ません。
  • セッション履歴は検索でき、14 日間活動のないセッションは自動でアーカイブされます（archiveInactiveSessions）。plan mode で終えた会話は plan mode で再開します（v2.1.246 以降）。
  • Session history の Web タブで、claude.ai のクラウドセッションを再開できます。会話のコピーをダウンロードするだけで、claude.ai には同期しません。Remote Control のセッションは、開いているフォルダのものならローカルの会話を開きます。
  • CLI 専用の機能: ! の Bash ショートカットと Tab 補完。コマンドと Skill は一部だけです。

JetBrains プラグイン Beta

  • IntelliJ IDEA・PyCharm・Android Studio・WebStorm・PhpStorm・GoLand などで動きます。プラグイン名と設定画面は Claude Code [Beta] です。
  • プラグインは IDE の統合ターミナルで claude を起動して接続します。CLI を同梱しないため、CLI を別途インストールします（PATH になければ Cannot launch Claude Code）。
  • 機能: Cmd+Esc での起動、IDE の diff ビューア、選択範囲とタブの共有、Cmd+Option+K でのファイル参照、診断の共有。
  • 外部ターミナルからは /ide で接続し、Connected to IntelliJ IDEA. のように表示されます。
  • 差分の表示先は /config の Diff tool（diffTool: auto か terminal）で、IDE に接続中だけ表示されます。
  • Settings → Tools → Claude Code [Beta] の Claude command で起動コマンドを変えます。WSL では wsl -d Ubuntu -- bash -lic "claude" のように指定します。
  • Remote Development では、プラグインをローカルではなくリモートホストに入れます（Settings → Plugin (Host)）。
  • WSL2 で No available IDEs detected になるのは、多くの場合 NAT ネットワークか Windows Firewall が原因です。Firewall の許可か mirrored ネットワークで直します。
  • Esc で中断できない場合は、ターミナル設定の「Move focus to the editor with Escape」を外します。

acceptEdits では、IDE が自動実行する設定ファイルを Claude が書き換え、Bash の確認を迂回しうると docs は警告しています。acceptEdits と auto mode は作業ディレクトリ内の編集を確認なしで通すため、編集は Manual を勧めています。

IDE MCP サーバー

  • 拡張・プラグインが有効なとき、ローカルの MCP サーバー ide が動き、CLI が自動で接続します。diff の表示、選択範囲の取得、Jupyter の実行に使います。設定項目がないため /mcp には表示されませんが、PreToolUse フックで MCP ツールを許可リスト管理している組織は、存在を知っておく必要があります。
  • 接続中は、各プロンプトに選択範囲と開いているファイルのパスが付き、⧉ Selected N lines from <file> と表示されます。Read の deny ルールに一致するファイルは渡しません。キューに入れたメッセージは Enter 時点の選択を保ちます。
  • 通信は loopback の ws:// で、ポートは変更できません（VS Code は 10000–65535 のランダム、JetBrains は OS 割り当て）。起動ごとのトークンを ~/.claude/ide/<port>.lock（VS Code では 0600、ディレクトリは 0700）に書き、CLI は X-Claude-Code-Ide-Authorization ヘッダーで提示します。
  • JetBrains の Accept connections from all network interfaces をオンにすると、ポートが LAN から届き、通信とトークンが平文で流れます。WSL2 では mirrored ネットワークを優先します。
モデルに見えるツール内容
mcp__ide__getDiagnosticsProblems パネル・インスペクションの診断（読み取り専用）
mcp__ide__executeCodeアクティブな Jupyter ノートブックで Python を実行。VS Code のみ
mcp__claude-vscode__getDiagnosticsVS Code のチャットパネル用の診断（v2.1.285 以降）
  • サーバー上の他のツールは CLI 自身の UI 用で、モデルに渡る前に除かれます。
  • executeCode は末尾にセルを追加し、VS Code の Quick Pick で Execute か Cancel を毎回確認します。ノートブックがない、Jupyter 拡張がない、カーネルが Python でない場合は拒否します。

診断を止めるには、mcp__ide__getDiagnostics と mcp__claude-vscode__getDiagnostics の両方を deny します。Read の deny はどちらにも効きません。executeCode を PreToolUse で許可しても、実行には Quick Pick の確認が要ります。

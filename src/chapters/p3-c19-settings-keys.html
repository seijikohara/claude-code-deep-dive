設定キー早見表

249 個の設定キーから、日常の調整でよく触るものを分野別に抜き出しました。1 キー 1 行で、既定値と要点だけを示します。全キーの一覧は 付録 A、ファイルの優先順位とマージは Ch18 を参照してください。スコープの列が無い行は Any file（4 種のファイルすべてに書ける）です。

モデルと応答

キー既定要点
modelアカウントの既定モデル新規セッションの開始モデル。途中の /model は妨げない
fallbackModel未設定（別モデルで再試行しない）過負荷・利用不可のときに順に試すモデルの配列。"default" は既定モデル
availableModels未設定（全モデル）メイン・サブエージェント・Skill・advisor で選べるモデルを制限
modelOverrides未設定Anthropic のモデル ID を、Bedrock の ARN などプロバイダ固有の ID に対応付け
modelSettings未設定モデルごとに effort を保存（2.1.251 以降）
effortLevel未設定"low"・"medium"・"high"・"xhigh"。保存の無いモデルの既定
maxEffortLevel未設定（上限なし）effort の上限。全スコープで最も低い上限が効く
alwaysThinkingEnabled未設定（対応モデルで思考オン）false で拡張思考をオフ。true は何も変えない
advisorModel未設定（advisor オフ）advisor のモデル Experimental（Ch5）
promptCacheTtl未設定メイン会話のキャッシュ TTL。"5m" か "1h"
language未設定既定の応答言語。固定の一覧は無く、値をそのまま Claude に渡す

permissions.disableBypassPermissionsMode未設定"disable" で bypassPermissions を禁止
disableAutoMode未設定"disable" で auto mode を Shift+Tab の巡回から外す

useAutoModeDuringPlanUser, local, or managed・trueplan mode でも分類器がシェルコマンドを審査
allowManagedPermissionRulesOnlyManageduser・project・local・--settings の権限ルールと --allowedTools を無視

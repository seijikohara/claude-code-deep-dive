Claude Code が受け付けるアカウントと資格情報、その優先順位を扱います。claude auth サブコマンド、Anthropic プロファイル、apiKeyHelper、claude setup-token、管理者がログイン方法と API プロバイダを絞るキーまでを説明します。プロバイダ固有の設定は Ch59 で扱います。

claude auth と資格情報の保存先

$ claude auth --help
Usage: claude auth [options] [command]

Manage authentication

Options:
  -h, --help        Display help for command

Commands:
  help [command]    display help for command
  login [options]   Sign in to your Anthropic account
  logout            Log out from your Anthropic account
  status [options]  Show authentication status
  • login のオプション: --claudeai（既定）、--console、--email <email>、--sso。
  • status は既定で JSON（--text で人向け）。ログイン済みなら終了コード 0、未ログインなら 1 です。
  • authMethod は none・claude.ai・oauth_token・api_key・api_key_helper・third_party。configDirectory は v2.1.268 以降、loginExpiresAt は 2.1.318 以降です。
  • JSON には docs に無いキーもあります: apiProvider、loggedIn、planTier、subscriptionType、storedClaudeAiLogin など Undocumented
  • 実機の authMethod: ANTHROPIC_API_KEY は api_key、ANTHROPIC_AUTH_TOKEN（API キーと併用でも）は oauth_token、CLAUDE_CODE_USE_* は third_party。

保存先と期限

  • macOS は Keychain です。SSH 中などで書き込みを拒まれると ~/.claude/.credentials.json（0600）に保存します。Linux も同じファイル、Windows は %USERPROFILE%\.claude\.credentials.json です。CLAUDE_CONFIG_DIR があればその下に置きます。
  • 期限の 3 日前から Your login expires in 3 days · run /login to renew、期限後は Login expired · Please run /login です。/status の Login 行は Expired — log in again になります（v2.1.210 以降）。

Anthropic プロファイルと、API キーを作らない Console サインイン

  • プロファイルは Anthropic 設定ディレクトリ（macOS・Linux は ~/.config/anthropic、Windows は %APPDATA%\Anthropic）にある資格情報ファイルです。認証モードは WIF 用の oidc_federation か、ant auth login などが書く user_oauth です。
ソース（上から確認）設定するもの/login との順位
名前付きプロファイルANTHROPIC_PROFILE上
federation 変数ANTHROPIC_FEDERATION_RULE_ID と ANTHROPIC_ORGANIZATION_ID の両方上
アクティブなプロファイルactive_config ファイル、または defaultoidc_federation なら上。user_oauth なら動いている /login より下
  • bare モード、Desktop、クラウドセッションはプロファイルを読みません。選ばれている間は claude.ai コネクタや /schedule が使えません。/status では Login method の代わりに Profile 行が出ます。

キーを作らない Console サインイン（v2.1.242 以降）

  • /login で Anthropic Console を選ぶと、Sign in with your Console account (recommended) と Create an API key (legacy) を選べます。前者は OAuth トークンをプロファイルとして保存し、API キーを作りません。
  • 書き込み先は ANTHROPIC_PROFILE、アクティブなプロファイル、default の順です。federation プロファイルは上書きせず拒否します。マシン上の claude.ai ログインからはサインアウトします。取り消しは /logout です。
  • 選択肢が出ず API キーを作る条件: クラウドプロバイダ（Claude Platform on AWS を含む）で動いている。forceLoginOrgUUID か forceLoginMethod: "claudeai" がどこかにある。"console" だけで失敗前。読めない managed ソースがあり、他に方針が無い。
  • 事前に ANTHROPIC_API_KEY を unset します。

apiKeyHelper と claude setup-token

apiKeyHelper

  • シェルコマンドの標準出力を資格情報として、X-Api-Key と Authorization: Bearer の両方で送ります。macOS・Linux は /bin/sh、Windows は cmd で実行します。例: "apiKeyHelper": "/bin/generate_temp_api_key.sh"
  • 値はキャッシュし、次のときに再実行します。
    • TTL 経過時。既定 5 分、CLAUDE_CODE_API_KEY_HELPER_TTL_MS で変更
    • Anthropic API（直接・LLM ゲートウェイ経由）が 401・403 を返したとき
    • gateway が 401（403 は除く）を返し、CLAUDE_CODE_SKIP_VERTEX_AUTH・_ANTHROPIC_AWS_AUTH・_MANTLE_AUTH のどれかが設定されているとき（v2.1.318 以降）
    • キャッシュが期限切れの JWT のとき、送信前に（v2.1.246 以降）
    • 後ろ 3 つはヘルパー出力を送り、ANTHROPIC_AUTH_TOKEN が無いときだけ
  • 10 秒超でプロンプトバーに警告。失敗・タイムアウト・空出力は 3 回以内に Your apiKeyHelper script is failing です。project・local 設定のものは workspace trust の承認まで実行せず、Desktop とクラウドセッションは呼びません。

claude setup-token

  • /login と同じブラウザ認可で 1 年有効 の OAuth トークンを表示します。保存はしないので、CLAUDE_CODE_OAUTH_TOKEN に設定します。
  • Pro・Max・Ultra・Team・Enterprise が必要です。できるのはモデル呼び出しだけで、Remote Control と claude.ai コネクタは使えません（ローカルの MCP は動く）。
  • --bare はこのトークンを読まないので、ANTHROPIC_API_KEY か apiKeyHelper を使います。forceLoginMethod は適用されますが、forceLoginOrgUUID は検査されないため、別組織のトークンも作れます。
  • Console の API キーは claude.ai 組織とは別の組織に属するため、CI で server-managed settings を効かせるには、このトークンか endpoint-managed settings を使います（Ch58）。
  • 自動プロビジョニング: CLAUDE_CODE_OAUTH_REFRESH_TOKEN と CLAUDE_CODE_OAUTH_SCOPES（例 "user:profile user:inference user:sessions:claude_code"）があると、claude auth login はブラウザを開かずに交換します。この 2 つと CLAUDE_CODE_OAUTH_TOKEN は project・local 設定の env では無視されます。

ログイン方法と組織を絞る: forceLoginMethod・forceLoginOrgUUID

  • forceLoginMethod: "claudeai"、"console"、"gateway"。"gateway" は forceLoginGatewayUrl と同じソースからだけ有効で、他では未設定扱いです。
  • v2.1.212 以降、VS Code・SDK・setup-token・/install-github-app でも強制します。ターミナルの対話ログイン画面だけは事前選択で、"claudeai" でも Console ログインを完了できます。
  • forceLoginOrgUUID（UUID か配列）を managed に置くと、claude.ai ログインは列挙した組織に限られます。使用中の claude.ai 資格情報が別組織なら起動時に終了します。Console ログインでは組織を事前選択するだけで検査しません。
  • managed 以外のファイルの forceLoginOrgUUID は組織を検査せず、単一 UUID なら事前選択するだけです（配列は何も選ばない）。
  • forceLoginOrgUUID か forceLoginMethod: "claudeai" がどこかにあると、キーを作らない Console サインインは提示されません。"console" だけなら失敗後の再試行で選べます。
ログイン以外の資格情報どちらかのキーがあるとき
ANTHROPIC_API_KEY・ANTHROPIC_AUTH_TOKEN・apiKeyHelper起動時にブロック。managed が渡した値でも同じ
Bedrock などのクラウドプロバイダ上の資格情報か保存済み Console キーが残っている間だけブロック
プロファイル・federation上の資格情報も残っているときだけブロック。組織は検査しない
  • 配布は MDM・ファイルで行います。server-managed settings は初回認証の後に届くので、最初のログインは誘導できません。
  • MDM・ファイルの値は server-managed より優先します。全クライアントが v2.1.299 以上になるまでは server-managed にも同じ値を置きます（Ch58）。
  • gateway サインインには forceLoginOrgUUID は効かず、IdP 側で絞ります。gateway が配る設定に両キーを入れません。
  • 不正な forceLoginOrgUUID は「どの組織もログイン不可」になります。

使える API プロバイダを絞る: allowedProviders

{
  "forceLoginMethod": "claudeai",
  "forceLoginOrgUUID": ["xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"],
  "allowedProviders": ["anthropic", "bedrock"]
}
値意味
"anthropic"Anthropic 自身のホスト（claude.ai・Console・API キー）
"bedrock"・"mantle"Bedrock Invoke API・Mantle。併用セッションは両方を列挙
"vertex"・"foundry"・"anthropicAws"Agent Platform・Foundry・Claude Platform on AWS
"customEndpoint"別ホストへ送る LLM ゲートウェイなど。managed env で固定した値と完全一致するときだけ許可
"gateway"Cloud gateway サインイン
  • managed のみ、v2.1.285 以降です。列挙外のプロバイダは起動時、ログイン時、セッション途中で切り替えた後の次の API 呼び出し時に拒否されます。
  • managed env での固定（pin）が要る経路: "customEndpoint" の ANTHROPIC_BASE_URL など。Bedrock の外を指す AWS_ENDPOINT_URL・AWS_ENDPOINT_URL_BEDROCK・AWS_ENDPOINT_URL_BEDROCK_RUNTIME（扱いは "bedrock" のまま）。gateway の URL（forceLoginGatewayUrl も pin になる）。
  • マシンの admin ソースのリストと server-managed のリストは積集合です。server-managed は狭められますが、広げられません。server-managed だけのリストは取得するセッションにしか届かないので、強制には使えません。
  • 知らない値は捨てて報告し、残りを強制します。空、または全部不明なリストは全プロバイダを拒否し、起動しません。
  • 資格情報、テナント変数、経路（HTTPS_PROXY・証明書）は判定しません。

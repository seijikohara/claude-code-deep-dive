Ch5 · Advisor

Advisor とは Experimental

  • メインモデルが作業中に、もう 1 つのモデル（advisor）へ相談するためのサーバー側ツールです。
  • advisor は会話全体を受け取ります。すべてのツール呼び出しとその結果も含みます。
  • いつ呼ぶかは Claude が決めます。呼びやすいのは次の 3 つの場面です。
    • 方針を決める前
    • 同じエラーが繰り返すとき
    • 完了を宣言する前
    どれも規則ではなく、モデルの判断です。
  • 呼び出し回数を制限したり、呼び出しを強制したりする設定はありません。相談させたいときはプロンプトで頼みます（例: consult the advisor before you continue）。
  • Claude は基本的に助言に従います。ただし、試した手順が失敗したときや、ファイルの内容が助言と矛盾するときは、無条件には従わずに食い違いを示します。

要件（すべて必要）

  • Anthropic API のみ: Bedrock・Claude Platform on AWS・Agent Platform・Foundry では使えません。LLM ゲートウェイ経由で使えるかは、ゲートウェイがリクエストをそのまま Anthropic API へ転送するかどうかで決まります。
  • 対応するメインモデル: Fable、Opus 4.6 以降、Sonnet 4.6 以降、Haiku 4.5、Haiku 5.5
  • feature flag の取得: advisor は Anthropic から取得する feature flag で有効になります。DISABLE_TELEMETRY など、取得を止める変数を設定すると、advisor は無効のままです。

ドキュメントには「挙動・価格・提供範囲は変わる可能性がある」と明記されています。

有効化の 3 経路と優先順位

経路書き方効く範囲と保存先
コマンド/advisor（ピッカー）・/advisor opus・/advisor off実行中のセッションで切り替わり、既定値として advisorModel に保存される。ピッカーには No advisor も並ぶ
設定"advisorModel": "opus"永続的な既定値。値は fable・opus・sonnet、または claude-opus-5-5 のような完全なモデル ID
フラグclaude --advisor opusそのセッションだけに効き、保存はしない。claude --help には載らない
無効化CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1/advisor が使えなくなり、advisorModel は無視される。--advisor は受け付けるが効果はない
  • 優先順位: 環境変数による無効化が最優先です。その次が --advisor、最後が advisorModel です。
  • 有効になると、起動時に通知が出ます: Advisor Tool (experimental) is on and may use more tokens · /advisor
  • --advisor は、次の場合に起動時エラーで終了します。
    • メインモデルが advisor に対応していない
    • 指定したモデルが advisor になれない
    • availableModels の許可リストに含まれていない
    • Fable の同意（後述）が済んでいない
    バックグラウンドセッションでは終了せず、advisor なしで起動します。
$ claude -p "/advisor"
Advisor: off
Usage: /advisor <fable|opus|sonnet|off>

$ claude -p --model sonnet --advisor opus "/advisor"
Advisor: Opus 5.5

user / local 設定を読ませない（--setting-sources project）空のディレクトリで実行

組み合わせの制約: advisor はメインモデル以上であること

メインモデル受け付ける advisor
Haiku 4.5Fable, Opus, Sonnet, Haiku 5.5
Sonnet 4.6Fable, Opus, Sonnet, Haiku 5.5
Opus 4.6Fable, Opus, Sonnet 5 以降, Haiku 5.5
Sonnet 5 / Haiku 5.5Fable, Opus 4.7 以降, Sonnet 5 以降, Haiku 5.5
Opus 4.7 / Opus 4.8Fable, Opus 4.7 以降, Sonnet 5.5
Sonnet 5.5Fable, Opus 5 以降, Sonnet 5.5
Opus 5 / Opus 5.5Fable, Opus 5 以降
Fable 5Fable 5.2, Fable 5.1, Fable 5
Fable 5.1Fable 5.2, Fable 5.1
Fable 5.2Fable 5.2
  • Haiku 4.5 は advisor を呼べますが、advisor にはなれません。
  • サブエージェントは advisor の設定を引き継ぎ、自分のモデルでもう一度組み合わせを検査します。
  • メインモデルより格下の advisor は、メインのリクエストには付けられません。ただし、条件を満たすサブエージェントは使えます。
  • API が組み合わせを拒否した場合、Claude Code はそのリクエストを advisor なしで再送します。エラーは表示されません。
  • 別の advisor を選び直した場合、反映されるのは /clear か /compact の後、または新しいセッションからです。
$ claude -p --model opus --advisor sonnet "/advisor"
"sonnet" cannot advise "claude-opus-5-5" (the advisor must be
at least as capable as the main model). The advisor will not
be used for the main model.          → exit 0（起動は続く）

$ claude -p --model claude-haiku-4-5 \
    --advisor claude-haiku-4-5 "/advisor"
Error: The model "claude-haiku-4-5" cannot be used as an advisor.
                                      → exit 1

セッション中の表示と、Fable を advisor にする条件

トランスクリプトの表示

呼び出し中は、advisor のモデル名とともに Advising の行が出ます。結果が返ると、行は次のいずれかに変わります。

結果表示と読み方
Reviewedadvisor が会話を確認した。助言の本文は Ctrl+O で読める
DeclinedAdvisor declined to advise on this request。理由があれば Ctrl+O で読める
UnavailableAdvisor unavailable (<error_code>)。呼び出しが失敗した

Fable advisor と usage credits

  • Fable の利用が usage credits に課金されるプランでは、Fable を advisor にした分も同じく課金されます。
  • 課金への 1 回限りの同意が済むまで、次のように扱われます。
    • /advisor fable は保存されず、/model fable の実行を案内される。
    • claude --advisor fable は起動時に終了する。バックグラウンドセッションでは advisor なしで起動する。
    • advisorModel に Fable が保存済みでも、リクエストは advisor なしで送られる。
  • 同意するには /model fable を実行し、Fable で続けることを選びます。そのあとで advisor に Fable を選びます。
  • バージョン要件があります。Fable 5.2 は v2.1.321 以降、Fable 5.1 は v2.1.257 以降、Haiku 5.5 は v2.1.293 以降が必要です。

コスト・プロンプトキャッシュ・他の手段との使い分け

  • コスト: advisor が会話を読むたびに、advisor モデルの料金でトークンを消費します。この分はメインモデルの利用とは別にかかります。
    • API 課金: advisor の入出力トークンを、advisor モデルの単価で支払う。
    • サブスクリプション: プランの利用上限に計上される（Fable は前スライドの usage credits）。
    • /usage のセッション合計に含まれる。
  • キャッシュ: /advisor の切り替えでは、メインモデルのキャッシュは壊れません（モデル切り替えとは違います）。
  • advisor 自身の会話の読み込みはキャッシュされません。呼ぶたびに、トランスクリプト全体を読み直します。

Claude Platform on AWS での提供可否が食い違っています。

  • advisor ページ: 「Claude Platform on AWS では使えない」
  • changelog 2.1.300: 「Added /advisor on Claude Platform on AWS」。advisor は /advisor・advisorModel・--advisor のいずれかで選ぶまで動きません。
手段強いモデルが動く時点開始のきっかけ
Advisor作業途中の判断の要所Claude が必要と判断して呼ぶ
opusplanplan mode の間（availableModels が許す場合）。実行時は Sonnet に切り替わるユーザーが plan mode に入る
model を指定したサブエージェント委譲したサブタスク全体Claude が委譲するか、ユーザーが呼び出す
/model次のリクエスト以降すべてユーザーが切り替える

速いメインモデルと強い advisor を組み合わせると、強いモデルを常時使うより安くなりやすい、とドキュメントは説明しています。
